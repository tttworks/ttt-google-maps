## このウィジェットでできること

### 座標を調べなくても配置できる

- **住所を入れるだけで地図が出る** —— 住所は自動的に座標へ変換されるため、
  編集する人が**緯度・経度を調べる必要はありません**。
- **ドラッグで位置を決めることも可能** —— エディタ上でマーカーを目標位置へドラッグすると、
  座標が自動で書き戻されます。
- **マーカーの数に制限なし** —— マーカーリストは利用者が自由に管理でき、
  パネル上で追加・削除・並べ替えができます。
- **住所・座標・その併用** —— 各マーカーの位置指定方法を個別に選べます。

### 見た目はどこまでも作り込める

- **9 種類の地図テーマを内蔵** —— すっきりした明るい配色から、暗く低彩度なトーンまで、
  プルダウンひとつで切り替えられます。
- **独自のスタイルも適用可能** —— カスタムのスタイル定義を貼り付ければそのまま反映されます。
  **地図のスタイルエディタで作れる見た目なら、すべてここで使えます。**
- **マーカーはひとつずつ設定** —— タイトル、テキストラベル、マーカー画像を個別に指定できます。
- **訪問者に許す操作を選べる** —— 地図のドラッグ、ホイールズーム、ズームコントロール、
  地図タイプの切り替え、縮尺、全画面、ストリートビュー、
  「Google マップで表示」リンク —— **それぞれが独立したスイッチです。**

### 実際のコンテンツ運用のために

- **地図の多言語対応** —— 地図自体のラベル言語を指定できます。
  **英語が第一言語でないサイト**では重要なポイントです。
- **高度な設定は邪魔をしない** —— 詳細なオプションは、対応する機能をオンにしたときだけ現れます。
  設定が深くなってもパネルは見やすく保たれます。
- **レスポンシブ標準対応** —— 見た目とサイズはデバイスごとに別々の値を持てます。
- **動的コンテンツに対応** —— マーカーの内容は動的なソースから流し込むこともでき、
  手入力に頼りません。
- **使用するページだけを読み込み** —— スタイルとスクリプトは、そのウィジェットを含むページにのみ
  読み込まれ、サイト全体には影響しません。

### エンジニアリング品質

- **依存関係なし** —— 素の JavaScript と CSS のみ。jQuery も CDN も不要です。
- **エディタに安全** —— 設定変更のたびにクリーンに再初期化され、
  マーカーの重複やイベントリスナーの残留が起きません。
- **ジオコーディングはキャッシュ** —— 編集中に同じ住所を何度も問い合わせないため、
  操作感が保たれ、不要な API 呼び出しも避けられます。
